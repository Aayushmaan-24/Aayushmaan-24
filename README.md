## 🛠️ What I Build
I build privacy-first, locally-run AI tools — no cloud dependency, no API keys, just models that work offline on your machine.

- 🎙️ **Smart Meeting Summarizer** — faster-whisper + local LLM pipeline that transcribes any audio/video and outputs structured notes, action items, and email drafts. 100% offline.
- 💬 **Financial RAG Chatbot** — deep learning chatbot fine-tuned on domain-specific data using retrieval-augmented generation
- 🔊 **Voice Transcriber** — on-device Whisper transcription with local AI cleanup, complete privacy
